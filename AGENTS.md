# Design system

This project's visual design follows [`DESIGN.md`](./DESIGN.md) (a Tesla-inspired system: single Electric Blue `#3E6AE1` accent reserved for primary CTAs, neutral grays elsewhere, no shadows/gradients, 4px radius on buttons/inputs and ~12px on larger cards, restrained typography at weight 400/500 only). Whenever you create or edit any screen, component, or style in this app, read `DESIGN.md` first and follow it — colors, spacing, radius, typography, and the Do's/Don'ts section. Don't introduce colors, shadows, or radii outside that system without asking the user first.
